# Contributing and extending this project

Thank you for your interest in this independent educational investigation of NASA Perseverance MEDA–TIRS data.

Possible next steps:

- Reproduce the six figures with the original PDS CAL_TIRS CSV/XML products.
- Review the provisional four-flag quality screen against the PDS metadata and MEDA RDR SIS; document instrument/viewing-geometry limitations.
- Replace the hardcoded summary-table strings with recalculated statistics.
- Fix the uncertainty section's nested-loop issue and standardize the LTST midday interval endpoint.
- Document observation coverage and uncertainty, then compare additional Martian sols without asserting unwarranted causal explanations.

Use a GitHub **Issue** for questions or suspected problems and a **Pull Request** for proposed changes. Please preserve units, exact source-product identifiers, NASA PDS provenance, and measurement gaps; do not relabel an exploratory output as validated mission science.

This repository is **not endorsed by NASA**.
