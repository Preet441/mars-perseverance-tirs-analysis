# Contributing and further research

Other students are welcome to explore the analyses and suggest ways to improve them. Use a GitHub Issue to describe a suspected error, alternative filtering rule or investigation idea; a Pull Request can propose changes to the included source script or documentation.

Potential next steps: reproduce each figure from the official PDS4 CSV/XML products, document instrument flags and masking, add uncertainty-aware comparisons, explore additional sols, and investigate the IR2 variability without presuming a single cause.

Please preserve links to NASA PDS source products, exact time standards, units, and gaps. This project is independent and is **not endorsed by NASA**.
